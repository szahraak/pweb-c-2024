## Assignment Detail

Kembangkan [Tugas 4 - JavaScript part 2](https://github.com/PWEB-C-2024/js-part-2-dev) menggunakan [Bootstrap CSS](https://getbootstrap.com/). Aplikasi harus memenuhi beberapa ketentuan berikut:

1. Terdapat judul aplikasi yaitu `Productivity Tracker App`.
2. Terdapat identitas pengembang aplikasi, yang berisi nama dan NRP.
3. Terdapat daftar aktivitas yang akan dilacak durasinya. Detail aktivitas terdiri atas nama aktivitas, timer, dua buah tombol start dan stop timer, dan target durasi yang ingin dicapai.
4. Terdapat satu buah tombol `Add Activity` untuk menambahkan aktivitas baru.
5. Terdapat sebuah tabel yang berisi riwayat pelacakan yang telah dilakukan oleh pengguna. Tabel berisi nama aktivitas, durasi yang ditempuh, target durasi yang ingin dicapai, serta persentase performa pada aktivitas tersebut.
